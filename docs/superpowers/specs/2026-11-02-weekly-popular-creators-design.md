# viSparkle — 週間人気クリエイター 設計書

- 作成日: 2026-11-02
- ステータス: 提案（PR でユーザーがレビュー）
- 前提: コア・決済・運営（サブプロジェクト1〜3）が main にマージ済み

## 1. 目的

ホームに「いま勢いのあるクリエイター」を出し、訪問者が応援先を見つけやすくする。現在のホームは「新着クリエイター」（登録順）しかなく、活動が盛り上がっているクリエイターが埋もれる。

## 2. 成功基準

1. ホームの「新着クリエイター」の上に「今週の人気クリエイター」を最大10人、順位つきで表示する
2. 順位は直近7日間に新しく支援を始めたファンの数で決まる
3. 活動終了したクリエイター、利用停止された会員のクリエイターは表示しない
4. 該当者が1人もいないときはセクションごと表示しない
5. 支援者数などの数値は公開しない（順位のみ）

## 3. 方式

| 項目       | 採用                                                              | 理由                                                                                                         |
| ---------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 人気の指標 | 直近7日間の**新規支援者数**                                       | 有料の支援はファンサイトで最も強い人気のシグナルで、既存の `supports` だけで集計できる。不正に水増ししにくい |
| 集計期間   | 現在時刻から7日前まで（ローリング）                               | 週の切り替わり（月曜0時など）に順位が空になるのを避ける                                                      |
| 集計方法   | リクエスト時に SQL で集計（`supports.status, started_at` に索引） | 集計テーブルやバッチは YAGNI。件数が増えたらキャッシュやバッチ集計に切り替える                               |
| 閲覧数     | 使わない                                                          | 閲覧数は累計値で「今週」を切り出せない。不正な水増しもしやすい                                               |

## 4. 集計ルール

対象の支援（`supports`）:

- `started_at` が直近7日以内
- `status = active`（期間中に始めてすぐ返金・利用停止で終了した支援は数えない。期間末の解約予約中は数える）
- 支援者がクリエイター本人でない

同じファンが同じクリエイターに有効な支援を2件持つことは決済の同期で防いでいるため、件数＝人数として扱う。

対象のクリエイター: `Creator::open()`（活動中で、本人が利用停止されていない）かつ上記の支援が1件以上。

並び順:

1. 直近7日間の新規支援者数が多い順
2. 同数なら、現在の有効な支援者の総数が多い順
3. それも同じなら、新しく登録したクリエイターが先（`id` の降順）

## 5. 画面

ホーム（`/`）のヒーローの直下、「新着クリエイター」の上に置く。

- 見出し: 「今週の人気クリエイター」
- 補足（小さく）: 「直近7日間に新しく支援を始めたファンが多い順です。」
- 各クリエイター: 順位（1〜10）、アバター、表示名。クリックでクリエイターページへ
- 並びはスマートフォンで横スクロール、PC では折り返し
- 該当者がいないときはセクションを描画しない

## 6. 実装

- `Creator` に `weeklyPopular` スコープを追加（`open()` を含み、`weekly_supporters_count` と `active_supporters_count` を `withCount` で付ける）
- `HomeController` が `Creator::weeklyPopular()->limit(10)` を `popularCreators` として渡す（形は既存の `CreatorSummary`）
- `resources/js/pages/public/home.tsx` にセクションを追加
- マイグレーションで `supports` に `(status, started_at)` の索引を追加

## 7. テスト

- 直近7日間の新規支援者数の順に並ぶ
- 7日より前に始まった支援、終了した支援、本人による支援は数えない
- 同数なら有効な支援者の総数で並ぶ
- 活動終了・利用停止のクリエイターは出ない
- 最大10人まで
- 該当者がいなければ空配列

## 8. 対象外（今後の検討）

- 投稿の閲覧数・いいね等を加味したスコア
- カテゴリ別のランキング、ランキング専用ページ
- 集計結果のキャッシュ・定期バッチ化（アクセスが増えた段階で）
