# クリエイターのフォロー Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 会員がクリエイターをフォローでき、フォロー先の無料の全体公開投稿がフィードの「すべて」タブに出るようにする。

**Architecture:** 新テーブル `follows`（`user_id` × `creator_id`）と `Follow` モデルで記録し、付け外しは `POST`/`DELETE /@{creator}/follow`（冪等）。新しい支援が有効になったとき `SubscriptionSync::write` が自動でフォローを付ける。フィードは `tab=all|supporting` で、「すべて」は「支援中の全投稿 OR フォロー中の無料投稿」を1クエリで引く。

**Tech Stack:** Laravel 13 / Pest / Inertia v3 + React + TypeScript / Wayfinder（`@/actions`・`@/routes`）/ MySQL（テストも MySQL、`RefreshDatabase`）

**Spec:** `docs/superpowers/specs/2026-11-02-follows-design.md`

## Global Constraints

- テスト・Artisan は Sail のコンテナで動かす: `docker compose exec -T laravel.test php artisan test ...`。PHPStan: `docker compose exec -T laravel.test vendor/bin/phpstan analyse --no-progress --memory-limit=1G`。Pint: `docker compose exec -T laravel.test vendor/bin/pint --test app tests database`。型: `npx tsc --noEmit`
- フォロー対象の投稿は `required_price = 0` のものだけ（フォローだけのクリエイターの有料投稿はフィードに出さない）
- フォロワー数はクリエイター本人の支援者ページだけ。公開ページの props に含めない
- ルート名: `creators.follow.store` / `creators.follow.destroy`。レート制限 `throttle:60,1,creator-follows`
- 画面の文言（そのまま使う）: 「フォロー」「フォロー中」「フォローできませんでした。」「フォローを外せませんでした。」「すべて」「支援中」「支援中・フォロー中のクリエイターの新着投稿」「支援中のクリエイターの投稿はまだありません。」「フォロワー」「（支援者を含みます）」
- コミットメッセージは日本語の Conventional Commits（`feat: ...`）。末尾に `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`
- ブランチ: `feat/follows`（設計書のコミット `15c3bab` を含む `docs/follows-spec` から切る）

## Review Focus

1. 支援中かつフォロー中のクリエイターの投稿が、フィードに**重複せず1回だけ**出ること → Task 4 のテスト `shows a post once when the creator is both supported and followed`
2. 支援中のクリエイターのフォローを外しても、「すべて」にその全投稿が出続けること → Task 4 のテスト `keeps supported creators in the feed after unfollowing`
3. フォロー中のクリエイターが利用停止されたら、フィードから投稿が消え、フォロー操作は 404 になること → Task 2 と Task 4 のテスト
4. 「支援中」タブの2ページ目へのリンクが `tab=supporting` を保つこと → Task 4 のテスト `keeps the tab in pagination links`
5. 活動終了のクリエイターをフォロー中の人は、ボタンで外せること（ボタンが消えて外せなくならない）→ Task 2 のテスト `lets a follower unfollow a closed creator` と Task 6 の画面確認
